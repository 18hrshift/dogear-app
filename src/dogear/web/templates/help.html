Help

Make a book

  1. On Your books, choose a book file and upload it. Dogear reads {{ book_formats }} files.
  2. Dogear reads the book to find its chapters. Then choose what to make, the voice, the speed, and which sections to read. A scanned PDF takes longer, a few seconds a page, because Dogear first reads the words in the pictures of its pages (OCR). The book's page says how far it has got.
  3. Choose Start making. A long book takes hours. The book's page says how far it has got, and you can close the page and come back.
  4. When it's ready, download what Dogear made from the book's page.

Fix how a word is said

The voice reads most English well, but can say names and made-up words wrong. To fix them:

  1. Before making a book, or on its page once it's made, choose "check how words are said". Dogear lists the words the voice doesn't know, most frequent first: the 50 that come up most, with a link to show the rest. The list stays with the book, even after Dogear restarts.
  2. Choose Listen beside a word to hear how the voice says it.
  3. If it sounds wrong, write how it sounds in "Say it like", with ordinary words or parts of words: Utterson as "utter son", say. Choose Save, then Listen again.
  4. Make the book, or make it again. Dogear uses your spellings in every book.

The Pronunciations page lists every word you have fixed. There you can change or remove them, add a word, and listen to any short text.

Save changes only the words you changed on the page. If one of them was changed in another window since you opened the page, Dogear saves nothing and says so beside that word.

If Dogear can't read a book

The book's page says why, and what to do. Once that's done (for a Kindle book, say, installing Calibre), choose Read again on the book's page.

A scanned PDF needs the free program Tesseract, which reads the words in the pictures of its pages. Dogear's installers don't include it, so if the page says it's missing, install it on the computer running Dogear, then choose Read again.

If there isn't room for a book

Before it speaks anything, Dogear checks that the computer has room for the book. If it doesn't, the book's page says how much space the book needs and how much is free. Free up some space, or choose fewer sections or kinds of book, then start it again.

Stopping and starting again

Stopping a book is safe. Every sentence Dogear has spoken is kept, so Start again carries on where it stopped.

Stopping while Dogear reads a scanned PDF is safe too. Every page it has read is kept, so Read again carries on with the next one.

Dogear makes one book at a time. Other books wait their turn.

Using Dogear from a phone

Start Dogear on the computer with dogear serve --lan. It shows a second link for phones and other computers on the same network. Open that link on the phone. Anyone on the network who has the link can use Dogear, so share it only with people you trust.

Keep Dogear running

This page works only while Dogear is running on the computer. Keep its window open. To stop Dogear, press Ctrl+C in that window, or close it. A book being made stops too, and Start again carries on later. A book that was being read is read again when Dogear next starts.
